# Audio controls and quieter master level

Remote report: NaN percentages, ineffective sliders and loud playback. The checked-in owner provides numeric values and setters, so remote code/import mismatch remains the likely cause; the remote bundle was not inspected. App now imports its audio owner and settings component by explicit relative paths, and the owner imports its settings utility relatively. This prevents host alias collisions from selecting an older audio hook. The combined import includes all matching audio files.

A shared 0.7 master gain makes both music and effects 70% of their previous amplitude at the same slider settings. Saved user percentages and 80%/60% defaults remain. Initial and live music gain share one helper; SFX applies the same attenuation in its synth gain calculation. Zero still mutes each channel independently.

Verification: unit suite 165 passed, two optional native export skips, no failures. Scoped TypeScript and production build passed. Built-browser journey used a generated silent one-second WAV to exercise actual Web Audio decoding/playback: invalid stored fields recover to 80/60, sliders show numeric percentages, music gain changes from .252 to .0882 at 28%, zero mutes, 100% yields .315, and settings persist across reload with no page errors. SFX gain attenuation is covered by numerical unit tests and its slider persistence by the browser journey. Physical playback loudness on the user's phone was not measured.
